FAQ

Windows says “Smart App Control blocked this app”

Smart App Control in Windows 11 blocks new apps that are not code-signed yet. Code signing is in progress; signed releases will run without this message.

On PCs without Smart App Control, SmartScreen may show “Windows protected your PC”. Click More info → Run anyway.

Why does the mouse move when help is given?

The game only accepts real mouse input. The helper waits until you are idle, clicks, and puts your cursor and active window back instantly.

Can I run it together with other bots?

Avoid running two tools that press the same help button at the same time.
